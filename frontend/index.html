🛡️ Proteção de Dados Pessoais (RGPD)

Responsável pelo tratamento: ISLA Santarém — Instituto Superior de Línguas e Administração de Santarém.

Finalidade: Os dados recolhidos durante este teste (nome, email e conversas) são utilizados exclusivamente para fins de avaliação, melhoria e validação da aplicação ISLA Assistente Académico.

Base legal: Consentimento do titular dos dados (Art.º 6.º, n.º 1, al. a) do RGPD).

Os teus direitos incluem:

  • Acesso aos teus dados pessoais
  • Retificação de dados incorretos
  • Eliminação dos dados ("direito ao esquecimento")
  • Portabilidade dos dados
  • Retirada do consentimento a qualquer momento

Conservação: Os dados serão conservados durante o período de avaliação do projeto e eliminados após a sua conclusão.

Confidencialidade: Os dados tratados de forma confidencial e não serão partilhados com terceiros.

Para exercer os teus direitos ou obter esclarecimentos, contacta o responsável pelo projeto académico.
